## Summary

Scope, architecture and the plan are documented, with concrete defaults for building the MVP. The planned app has two outputs: ranked, captioned 9:16 clips and a 16:9 highlights video. The initial setup targets a laptop; collection/storage can be shared and hosted deployment remains an option. The Python package has a `synth` command for deterministic fake VOD datasets, configuration, logging, a shared FFmpeg runner, a Helix metadata client, viewer-clip fetching, a pseudonymizing chat replay parser, VOD audio download with 16 kHz mono normalization, vertical-MP4 export (cut, reframe, burned-in captions, encode; `autoclipper export` and the API's export endpoints), VOD time windows and viewer-clip moments, chat and audio features per window, the step-1 evaluation, candidate generation in the `AnalysisResult` format, the four baselines, and a mock backend API (`autoclipper serve`). Python and frontend tooling run in CI. The Next.js frontend has the start, progress and results screens, running against a mock API client. **There is no real dataset, trained model or analysis pipeline yet; the backend runs mock jobs.** No results exist.
